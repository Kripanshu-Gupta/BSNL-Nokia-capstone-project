BSNL & Nokia AIML Training - Capstone Project Showcase

This project is a responsive, single-page web application built to showcase the skills and experience gained during the Advanced AI/ML Training program offered by BSNL and Nokia in Jabalpur.

Live Demo

You can view the live deployed project here:

https://sweet-gaufre-f1f9d9.netlify.app/

About The Project

This web application serves as a dynamic portfolio piece summarizing the 5-day intensive classroom training on Telecom Data Analytics. It highlights the course curriculum, key concepts learned, the mentors who led the training, and moments from the workshop.

Key Features

Fully Responsive Design: The layout adapts seamlessly to all device sizes, from mobile phones to desktop monitors.

Light & Dark Mode: A theme toggle allows users to switch between a light and dark version of the site for comfortable viewing.

Interactive Photo Gallery: A clean, grid-based gallery showcases photos from the training workshop with a smooth modal view for larger images.

Dynamic Content: Built with React, the application uses state management for interactive elements like the theme switcher and image modal.

Custom CSS Styling: The project is styled with pure CSS, demonstrating control over design without reliance on utility frameworks.

Technologies Used

React: A modern JavaScript library for building user interfaces.

Vite: A next-generation frontend tooling for fast development and optimized builds.

CSS3: Custom styling for layout, themes, and animations.

JavaScript (ES6+): For application logic and interactivity.

Netlify: For continuous deployment and hosting.

How to Run This Project Locally

To get a local copy up and running, follow these simple steps.

Clone the repository:

git clone [https://github.com/Kripanshu-Gupta/BSNL-Nokia-capstone-project.git](https://github.com/Kripanshu-Gupta/BSNL-Nokia-capstone-project.git)


Navigate into the project directory:

cd BSNL-Nokia-capstone-project


Install NPM packages:

npm install


Run the development server:

npm run dev


The application will now be running on http://localhost:5173.
